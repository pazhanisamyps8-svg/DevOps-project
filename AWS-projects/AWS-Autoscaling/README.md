🚀 AWS Auto Scaling Project Completed Successfully!
I'm happy to share that I have successfully deployed an AWS Auto Scaling solution integrated with a Classic Load Balancer.
🔹 Project Highlights:
✅ Created a custom Amazon Machine Image (AMI) from a configured EC2 instance.
✅ Configured an Auto Scaling Group (ASG) using the custom AMI.
✅ Set the minimum capacity to 2 EC2 instances to ensure high availability.
✅ Configured Auto Scaling policies to automatically launch 2 additional EC2 instances when the workload increases, scaling from 2 to 4 instances.
✅ Integrated the Auto Scaling Group with a Classic Load Balancer to distribute incoming traffic across healthy instances.
✅ Enabled Amazon SNS (Simple Notification Service) to receive email notifications whenever Auto Scaling events occur, such as instance launch, termination, and scaling activities.
💡 Key Learnings:
Creating reusable AMIs for automated deployments.
Configuring Auto Scaling Groups and scaling policies.
Load balancing traffic using AWS Classic Load Balancer.
Monitoring infrastructure and receiving real-time alerts with Amazon SNS.
Building a highly available and scalable AWS environment.
This hands-on project strengthened my understanding of AWS compute services, high availability, automatic scaling, and infrastructure monitoring.
