🚀 Hands-on AWS Load Balancer Project Completed!
Happy to share that I successfully configured and tested both Classic Load Balancer (CLB) and Application Load Balancer (ALB) in AWS as part of my cloud learning journey.
✅ Classic Load Balancer (CLB)
Created 2 Amazon EC2 instances.
Installed and configured Apache HTTP Server (httpd) on both instances.
Configured a Classic Load Balancer to distribute HTTP traffic across the two web servers.
Successfully verified load balancing and high availability.
✅ Application Load Balancer (ALB)
Launched 6 Amazon EC2 instances across multiple Availability Zones.
Created 3 Target Groups, with 2 EC2 instances in each target group.
Configured an Application Load Balancer with listener rules to route requests to the appropriate target groups.
Successfully tested traffic distribution and routing across all target groups.
