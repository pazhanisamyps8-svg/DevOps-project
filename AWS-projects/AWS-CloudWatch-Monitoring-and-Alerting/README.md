✅ Scenario 1: EC2 CPU Utilization Threshold Alarm

Successfully received email notifications via Amazon SNS whenever the alarm entered the ALARM state.
✅ Scenario 2: EC2 Instance State Change Monitoring
Configured Amazon EventBridge and CloudWatch to monitor EC2 instance state changes.
Successfully received alerts and email notifications for events such as:
▶️ Instance Start
⏹️ Instance Stop
🔄 Reboot
❌ Terminate
✅ Scenario 3: Linux Service Monitoring
Configured the Apache (httpd) service on an EC2 instance.
Wrote a Bash script to continuously monitor the service status.
Whenever the httpd service stops or becomes unavailable, the script triggers a CloudWatch alarm, and an email notification is sent automatically.
