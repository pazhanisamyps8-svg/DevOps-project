🚀Hands-on AWS Project Completed. From Domain Registration to a Secure Website on AWS – Hands-on with Route 53, Load Balancer & ACM 🚀

Another exciting milestone in my AWS learning journey! 🎉
I recently purchased my own domain and successfully deployed a simple online shopping website on AWS. This project gave me practical experience in configuring DNS, securing web traffic, and making a website accessible through a custom domain.
🔹 What I implemented
✅ Purchased and configured a custom domain.
✅ Created an Amazon Route 53 Hosted Zone and connected it with my domain registrar.
✅ Configured an A Record to map my root domain to the web server.
✅ Configured a CNAME Record for the www subdomain, pointing it to an Application Load Balancer. Since the Load Balancer generates a long AWS DNS name, the CNAME record allows users to access the application using a simple custom domain instead.
✅ Configured an Application Load Balancer (ALB) to handle incoming traffic.
✅ Requested and validated an SSL/TLS certificate using AWS Certificate Manager (ACM).
✅ Attached the ACM certificate to the Load Balancer and enabled HTTPS, ensuring encrypted and secure communication.
🌐 The result is a fully functional website that is accessible through a custom domain with a secure HTTPS connection.
Every hands-on project helps me better understand how AWS services integrate in real-world deployments. Looking forward to building more cloud solutions and continuing my learning journey.
